MCP servers

Registered for every session on this machine, in every CLI installed here (claude) — the same user scope claude mcp add / codex mcp add / agy mcp add write to, but without putting your token on a command line.
The server is contacted with tools/list before anything is written. A server that refuses leaves every config untouched.

Media tools

Agents edit video and audio by running these commands in their own terminal, so they have to be installed on the machine running the orchestrator — nothing here ships with it. Install what is missing, then press Re-check.

Sounds

Find a video, pull its sound out, keep it. Runs yt-dlp and ffmpeg on the machine the orchestrator runs on. Check a sound's licence before you ship it.

Edit sound

Speak text

English text to natural speech, made on this machine with Kokoro (Apache-2.0) — nothing is sent anywhere. Speech goes to a temp folder and is cleared when the computer restarts.

Images
