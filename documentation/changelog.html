Changelog

What changed in each release, newest first.

Unreleased

Changes since v2026.08.12-1.

New

  • Director and sub-agents: one agent splits the work, others build it in their own git worktrees.
  • Independent verifier: work counts as done only after a fresh agent observes its Done means.
  • Four sub-agent playbooks: feature, bugfix, refactor, investigate.
  • Team tab: a pipeline board, the director's decision log, who may message whom, models per role.
  • Reflect: turns failed runs into a playbook change you approve.
  • Antigravity (Gemini) CLI support, with models read from agy models.
  • Home inbox: approvals and failed sub-agents across all workspaces.
  • Command palette: Ctrl K or ⌘ K to jump anywhere or run an action.
  • Groups above workspaces; rename or delete a workspace in one step.
  • Settings › Performance: what is using your CPU and memory, in plain words.
  • Settings › Removed agents: delete leftover runs and transcripts for good.
  • Settings › Media tools: shows which media commands agents can use on this machine.
  • Tool servers register for every installed CLI, without a token on the command line.
  • Folder card: browse a project's files on the canvas.
  • Pick which past CLI session a card resumes, and delete old ones.
  • Rename an agent; its old name keeps working.
  • Shift + scroll zooms the canvas, even over a terminal.
  • A row of chips above the canvas jumps to any card.

Changed

  • New dashboard design: left sidebar, new fonts, Settings as a full page.
  • Activity is one timeline of messages and runs, with live transcripts.
  • Agent details moved into a tabbed panel: Overview, Work, Settings.
  • New agent is a three-step dialog.
  • Every card is a terminal card.
  • Safer defaults: the server listens on your machine only, and CORS is off.
  • Requests from other websites are refused.
  • Claude model lists updated to the current models.
  • Agents are told to signal only after their own turn is finished.
  • Team tab loads 10 cards and decisions at a time as you scroll.

Removed

  • Codex CLI support.
  • VS Code cards. Use the folder card instead.
  • The API key setting: this is a local app, reachable from your own machine by default.
  • The prebuilt Linux download. Linux runs from source.
  • Unity tooling and the asset_fetch tool server.
  • The Compact context and Signal buttons in the agent panel. Messages go through the box at the bottom of the panel.

Fixed

  • A report no longer triggers a report back.
  • A slash command in a message reaches the CLI as a command, not as text.
  • The dashboard no longer slows down after hours of work.
  • Ctrl-C stops the server cleanly instead of hanging.
  • Selecting text in a card picks the right line at any zoom.
  • A card whose transcript was deleted opens again instead of dying.
  • Changing a card's model to another CLI is no longer refused.
  • Icons from Nerd Fonts no longer show as empty boxes in terminals.
  • CLAUDE_CONFIG_DIR is respected when finding transcripts.
  • The dashboard can no longer serve a stale version to some workspaces.
  • Windows: CLI transcripts are matched to a folder by its real path.

Older releases are on GitHub Releases.
